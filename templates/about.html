About ToDoz App

A simple and efficient task management application built with Flask and SQLite.

Our Mission

Our goal is to provide a clean and user-friendly platform that helps users organize their daily tasks. This project demonstrates the fundamentals of web development using Python Flask and SQLite.

Features

  • Create new tasks
  • Update existing tasks
  • Delete completed tasks
  • Store data securely using SQLite
  • Responsive and easy-to-use interface

Technologies Used

Python Flask SQLite HTML CSS

Developer

This Todo application was developed as a learning project to practice Flask, SQLite, CRUD operations, and web development concepts.

Thank you for visiting and using this application.
